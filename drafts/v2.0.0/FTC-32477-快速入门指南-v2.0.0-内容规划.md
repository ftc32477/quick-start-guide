## 1. 背景与依据

### 1.1 指南定位（摘自 README）

- 定位：**工具书，准确性优先**；初次阅读能顺畅通读，工作中能快速检索（多用小标题、编号步骤、表格）。
- 文本流转：简体中文为唯一源头，单向翻译到其余六语言。
- 现有结构：前言 + 七个章节（队员须知 / 建模设计 / 结构建造 / 程序设计 / 外部联络 / 后记）+ 网站主页 + 历史版本页。

### 1.2 内容评审结论（v1.5.1 之后）

v1.5.1 解决了准确性层面的勘误（pt-br 语言包链接、CycleZLab 注记、繁体封面副题等），内容层面仍有三组结构性矛盾：

1. **"工具书"却偏环境开通**：账号注册、软件安装、网络配置、团队现状占比较高；"读完能做什么"的内容偏少。
2. **三条技能主线只有骨架**：程序设计章约六成是 GitHub 协作；结构建造约一半是工具/材料介绍；建模章缺可跟做的完整示例。
3. **比赛全链路缺一段**：从赛季规则、赛制、策略、Scouting、Drive Team 到 Pit/检录/检查/复盘，整条"比赛运营"线没有落点。

## 10. 发版流程（v2.0.0）

### 10.1 版本数据

- `RELEASE_TAG = "v2.0.0"`；`VERSIONS` 顶部新增条目（12 → 13 条）：

    - en-us：`December 2026, 1st Edition`
    - fr：`Décembre 2026, 1re édition`
    - es：`1.ª edición, diciembre de 2026`
    - ko：`2026년 12월 제1판`
    - pt-br：`dezembro de 2026, 1.ª edição`
  - changes 七语言：**结构性大改版**——新增章节与页面、各章补强、图表/模板/清单体系、pt-br 审校、语言包修正、README/工程维护；
  - pdfs：7 个 v2.0.0 文件名。
- 七语言 `afterword.md` 末行落款同步版次；
- README 中当前版本示例（PDF 文件名、版权页示例、页数公式）同步。

### 10.2 构建与自查

- `python3 build.py` → `dist/` 与源码同步；
- `python3 build_pdf.py` → 7 份 PDF；
- 按 §9.4 回归清单逐项验证；
- release 通道验证：在 main 上构建检查 canonical/hreflang、无 noindex。

### 10.3 发布步骤（沿用 v1.5.1 修正后的流程）

1. `release-notes/v2.0.0.md` 定稿并入库；
2. `git checkout dev` 确认干净、内容冻结；
3. `./release.sh v2.0.0 release-notes/v2.0.0.md`（构建 → 提交 → 确认 tag 推送 → 确认 Release 上传 7 PDF → 确认推 dev → 清理旧 PDF → 确认合并 main 重建推送）；
4. 发布后核对：Release `publishedAt` 本地日期 = VERSIONS `date`；7 资产齐全；正式站/预览站/canonical/noindex/下载链接验证；
5. 关闭 README 待办中已完成项；更新 v2.0.0 之后的规划（v2.1.0 候选）。

### 10.4 勘误预案

- 发布后发现内容错误：走 v2.0.1 勘误（当月版次·第 N 次修订），修订 VERSIONS/README/后记/PDF 后按流程发布；不直接改 Release 资产。
- 翻译问题按语言分别走勘误，不阻塞其他语言。
