### FTC 32477 Origin Quick Start Guide · September 2026, 1st Edition · Revision 1

This revision upgrades the typography of the offline (PDF) guides in all six languages:

- 简体中文 (zh-Hans)
- 繁體中文 (zh-Hant)
- English (US)
- Français
- Español
- 한국어 (ko)

Typography:

- Body text is now set in Source Han Serif, headings in Source Han Sans, and quotations, captions and the preface in LXGW WenKai (a Kai-style face). Latin text and figures prefer Times New Roman, falling back to the metric-compatible open-source Tinos.
- Headers and footers are now stamped by the build script using embedded font subsets, so running heads and page numbers look identical on every platform.
- CJK text now uses proper embedded Type0 font subsets instead of many fragmented Type3 fonts: text is searchable and copyable, and file size is roughly halved.
- Fonts are subset to the characters actually used and shipped with the repository (about 10 MB): teammates can build offline with no font installation, and the build verifies character coverage automatically.

Printing & binding:

- The PDF now follows a textbook-style binding. Since the printer cannot print the inside front/back covers, the front cover and back cover are printed separately, and the interior begins with a white title page (cover information set in black on white) whose reverse is the copyright page, followed by the preface, the table of contents and the main text.
- The Resources & Updates page moves into the book block as the last interior page; when needed, a blank page is inserted before the back cover so that the interior has an even page count. Roman numeral I and Arabic page 1 both fall on right-hand pages (even-left/odd-right pagination).

The website edition is unaffected and continues to use system fonts.

For the online edition, visit: <https://ftc32477.github.io/docs/index.html>
