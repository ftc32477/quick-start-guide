### FTC 32477 Origin Quick Start Guide · August 2026, 3rd Edition, 2nd Revision

This release publishes the offline (PDF) edition of the **FTC 32477 Origin Quick Start Guide, August 2026, 3rd Edition, 2nd Revision**, in six languages:

- 简体中文 (zh-Hans)
- 繁體中文 (zh-Hant)
- English (US)
- Français
- Español
- 한국어 (ko)

Changes in this revision:

- Traditional Chinese edition: the Onshape terms 「结构体/装配体」 are now written in traditional characters (結構體/裝配體).
- Version history page: clarified that earlier versions include only the languages available at their release.
- PDF cover and back cover: the version information is now set on two lines with increased line spacing; the back cover lines are right-aligned.
- Engineering updates: edition data is now fully data-driven from VERSIONS (sidebar footer, homepage latest version, PDF cover date); added a check-dist CI workflow and a semi-automated release script (release.sh); Release notes are archived in release-notes/; all pages now include SEO/social-sharing meta tags and localized accessibility labels; --watch now monitors images/ and build.py as well.

The guide contains 7 chapters: Preface, Team Essentials, Modeling & Design, Hardware & Build, Programming, Outreach & PR, and Afterword. It helps new members get started quickly and serves as a working baseline for returning members. Compiled by the editorial team of FTC Team 32477 Origin, Beijing National Day Experimental School. This guide is an independent publication of the team and is not affiliated with FIRST®.
