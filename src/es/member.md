### Entorno de red

#### Red local

El taller dispone de red local cableada e inalámbrica. El nombre de la red inalámbrica es `BNDES-FTC`, la puerta de enlace es `192.168.3.1` y el estándar inalámbrico es 802.11ax.

Consulte al administrador la contraseña.

#### Internet

Para las operaciones concretas, consulte al administrador.

### LocalSend

LocalSend es la herramienta de transferencia de archivos en la red local que utiliza nuestro equipo.

**Proceso de instalación (ejemplo con la versión v1.17.0):**

> [!warning] En **iOS**: abra [https://apps.apple.com/us/app/localsend/id1661733229](https://apps.apple.com/us/app/localsend/id1661733229) e instálela.

1. Abra [https://localsend.org/zh-CN/download](https://localsend.org/zh-CN/download)
2. O acceda al repositorio de GitHub: [https://github.com/localsend/localsend/releases](https://github.com/localsend/localsend/releases)
3. Desplace la página hacia abajo y, en la lista Assets de la última versión, pulse "Show all assets" para mostrar todas las versiones disponibles
4. Descargue la versión correspondiente e instálela

**Descripción de las versiones por plataforma:**

- **Android:**
  - `-android-arm32v7.apk`: compilada para CPU ARM de 32 bits de 7.ª generación
  - `-android-arm64v8.apk`: compilada para CPU ARM de 64 bits de 8.ª generación
  - `-android-google-play.apk`: compilada para Google Play (puede requerir los servicios de Google Mobile Services)
  - `-android-x64.apk`: compilada para arquitectura x86 de 64 bits
- **Linux:**
  - `-linux-arm-64.deb`: paquete .deb para sistemas Debian/Ubuntu con arquitectura ARM de 64 bits
  - `-linux-arm-64.tar.gz`: paquete comprimido universal para Linux con arquitectura ARM de 64 bits
  - `-linux-x86-64.AppImage`: ejecutable AppImage para Linux con arquitectura x86 de 64 bits
  - `-linux-x86-64.deb`: paquete .deb para sistemas Debian/Ubuntu con arquitectura x86 de 64 bits
  - `-linux-x86-64.tar.gz`: paquete comprimido universal para Linux con arquitectura x86 de 64 bits
- **Windows:**
  - `-windows-x86-64.exe`: instalador para arquitectura x86 de 64 bits
  - `-windows-x86-64.zip`: paquete comprimido portátil (sin instalación) para arquitectura x86 de 64 bits
- **macOS:**
  - `.dmg`: imagen de disco instalable para macOS

### GitHub

GitHub es el repositorio de almacenamiento de material de código abierto que utiliza nuestro equipo.

**Proceso de registro:**

1. Abra [https://github.com/signup](https://github.com/signup)
2. Siga las indicaciones para crear una cuenta personal
   - Durante el registro, el sistema pedirá verificar la dirección de correo electrónico
   - Recomendamos seleccionar «Estados Unidos» como país/región
3. Tras registrarse, comunique su nombre de usuario al administrador y espere a que le envíe la invitación para unirse a la organización. Puede consultarla en [https://github.com/notifications](https://github.com/notifications).

A continuación, ya puede consultar y modificar los repositorios en [https://github.com/orgs/ftc32477/repositories](https://github.com/orgs/ftc32477/repositories).

**Referencias:**

- [Documentación de GitHub sobre cómo crear una cuenta](https://docs.github.com/zh/get-started/start-your-journey/creating-an-account-on-github)

### Onshape

Onshape es la plataforma de modelado 3D en la nube que utiliza nuestro equipo.

Todas las cuentas de Onshape del equipo utilizan el plan educativo gratuito (Education Plan).

**Proceso de registro:**

1. Abra la página de registro del plan educativo: [https://www.onshape.com/en/education/sign-up](https://www.onshape.com/en/education/sign-up)
2. Rellene el formulario de registro y envíelo

Referencias:

- [Información sobre el plan educativo de Onshape](https://www.onshape.com/en/education/plans)
