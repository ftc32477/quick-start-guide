### LocalSend

LocalSend 是我队采用的局域网文件传输工具。

**安装流程（以 v1.17.0 版本为例）：**

> [!warning] 对于 **iOS** 系统：打开 [https://apps.apple.com/us/app/localsend/id1661733229](https://apps.apple.com/us/app/localsend/id1661733229) 安装即可。

1. 打开 [https://localsend.org/zh-CN/download](https://localsend.org/zh-CN/download)
2. 或进入 GitHub 仓库：[https://github.com/localsend/localsend/releases](https://github.com/localsend/localsend/releases)
3. 下滑页面，在最新版本的窗口下的 Assets 列表中点击"Show all assets"来显示所有可用版本
4. 下载对应版本并安装即可

**各平台版本说明：**

- **Android 系统：**
  - `-android-arm32v7.apk`：针对 32 位 ARM 第 7 代 CPU 架构所构建的版本
  - `-android-arm64v8.apk`：针对 64 位 ARM 第 8 代 CPU 架构所构建的版本
  - `-android-google-play.apk`：针对 Google Play 商店所构建的版本（可能需要 Google Mobile Services 支持）
  - `-android-x64.apk`：针对 64 位 x86 架构所构建的版本
- **Linux 系统：**
  - `-linux-arm-64.deb`：针对 64 位 ARM 架构 Debian/Ubuntu 等系统所构建的 Deb 安装包版本
  - `-linux-arm-64.tar.gz`：针对 64 位 ARM 架构 Linux 系统所构建的通用压缩包版本
  - `-linux-x86-64.AppImage`：针对 64 位 x86 架构 Linux 系统所构建的 AppImage 可执行版本
  - `-linux-x86-64.deb`：针对 64 位 x86 架构 Debian/Ubuntu 等系统所构建的 Deb 安装包版本
  - `-linux-x86-64.tar.gz`：针对 64 位 x86 架构 Linux 系统所构建的通用压缩包版本
- **Windows 系统：**
  - `-windows-x86-64.exe`：针对 64 位 x86 架构所构建的安装程序版本
  - `-windows-x86-64.zip`：针对 64 位 x86 架构所构建的免安装压缩包版本
- **macOS 系统：**
  - `.dmg`：针对 macOS 系统所构建的磁盘镜像安装包版本

### GitHub

GitHub 是我队采用的开源资料存储仓库。

**注册流程：**

1. 打开 [https://github.com/signup](https://github.com/signup)
2. 按照提示创建个人帐户
   - 注册期间，系统会要求验证电子邮件地址
   - 我们建议将国家/地区选项选择为"美国"
3. 注册完成后，请向管理员告知你的用户名，并等待管理员向你发来加入组织邀请。你可以在 [https://github.com/notifications](https://github.com/notifications) 查收。

而后，你就可以在 [https://github.com/orgs/ftc32477/repositories](https://github.com/orgs/ftc32477/repositories) 查看、修改仓库了。

**参考资料：**

- [GitHub 创建帐户文档](https://docs.github.com/zh/get-started/start-your-journey/creating-an-account-on-github)
