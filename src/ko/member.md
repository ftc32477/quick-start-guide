### LocalSend

LocalSend는 우리 팀이 사용하는 LAN 파일 전송 도구입니다.

**설치 절차(v1.17.0 버전 기준):**

> [!warning] **iOS**의 경우: [https://apps.apple.com/us/app/localsend/id1661733229](https://apps.apple.com/us/app/localsend/id1661733229)를 열어 설치하면 됩니다.

1. [https://localsend.org/zh-CN/download](https://localsend.org/zh-CN/download) 열기
2. 또는 GitHub 저장소 접속: [https://github.com/localsend/localsend/releases](https://github.com/localsend/localsend/releases)
3. 페이지를 아래로 내려 최신 버전 창의 Assets 목록에서 "Show all assets"를 클릭해 모든 사용 가능한 버전 표시
4. 해당 버전을 다운로드하여 설치

**플랫폼별 버전 설명:**

- **Android:**
  - `-android-arm32v7.apk`: 32비트 ARM 7세대 CPU 아키텍처용 빌드
  - `-android-arm64v8.apk`: 64비트 ARM 8세대 CPU 아키텍처용 빌드
  - `-android-google-play.apk`: Google Play 스토어용 빌드(Google Mobile Services 지원이 필요할 수 있음)
  - `-android-x64.apk`: 64비트 x86 아키텍처용 빌드
- **Linux:**
  - `-linux-arm-64.deb`: 64비트 ARM 아키텍처 Debian/Ubuntu 등 시스템용 Deb 설치 패키지
  - `-linux-arm-64.tar.gz`: 64비트 ARM 아키텍처 Linux 시스템용 범용 압축 패키지
  - `-linux-x86-64.AppImage`: 64비트 x86 아키텍처 Linux 시스템용 AppImage 실행 버전
  - `-linux-x86-64.deb`: 64비트 x86 아키텍처 Debian/Ubuntu 등 시스템용 Deb 설치 패키지
  - `-linux-x86-64.tar.gz`: 64비트 x86 아키텍처 Linux 시스템용 범용 압축 패키지
- **Windows:**
  - `-windows-x86-64.exe`: 64비트 x86 아키텍처용 설치 프로그램 버전
  - `-windows-x86-64.zip`: 64비트 x86 아키텍처용 무설치 압축 패키지
- **macOS:**
  - `.dmg`: macOS용 디스크 이미지 설치 패키지

### GitHub

GitHub는 우리 팀이 사용하는 오픈소스 자료 저장소입니다.

**가입 절차:**

1. [https://github.com/signup](https://github.com/signup) 열기
2. 안내에 따라 개인 계정 생성
   - 가입 과정에서 이메일 주소 인증을 요구합니다
   - 국가/지역은 '미국' 선택을 권장합니다
3. 가입 후 관리자에게 사용자 이름을 알리고 조직 초대를 기다립니다. [https://github.com/notifications](https://github.com/notifications)에서 확인할 수 있습니다.

이후 [https://github.com/orgs/ftc32477/repositories](https://github.com/orgs/ftc32477/repositories)에서 저장소를 보고 수정할 수 있습니다.

**참고 자료:**

- [GitHub 계정 만들기 문서](https://docs.github.com/zh/get-started/start-your-journey/creating-an-account-on-github)

### Onshape

Onshape는 우리 팀이 사용하는 클라우드 3D 모델링 플랫폼입니다.

팀의 모든 Onshape 계정은 무료 교육 플랜(Education Plan)을 사용합니다.

**가입 절차:**

1. 교육 플랜 가입 페이지 열기: [https://www.onshape.com/en/education/sign-up](https://www.onshape.com/en/education/sign-up)
2. 가입 양식을 작성하고 제출하면 됩니다

참고 자료:

- [Onshape 교육 플랜 안내](https://www.onshape.com/en/education/plans)
