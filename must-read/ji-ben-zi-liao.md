# 基本资料

以下是所有队员均需准备的资料。

#### （一）设备 <a href="#devices" id="devices"></a>

以下选项任一即可。

1. 搭载Windows 10及以上的电脑；
2. 搭载macOS 13及以上的电脑。

#### （二）网络环境

需要具备可以获取Android支持的网络环境。

Android支持：[https://support.google.com/android](https://support.google.com/android)

#### （三）应用程序

1. 网络浏览器（Chrome或Edge或Safari）
2. LocalSend

#### （四）在线账户

1. 电子邮箱（推荐使用 @gmail.com 或 @outlook.com）
2. GitHub  [https://github.com/](https://github.com/)
3. Onshape  [https://www.onshape.com/](https://www.onshape.com/)

除此之外，建模设计、结构建造、程序设计、外部联络均有各自需要追加的资料。
